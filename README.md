# 株信用チェッカー

銘柄コードまたは銘柄名で検索して、**信用買い残・信用売り残・信用倍率・前週比(株数と%)** を表示するサイトです。信用残の推移グラフ、週次履歴テーブル、株価レンジ(上場来・年初来)、決算発表予定日も表示します。

ローカル(`node server.js`)でも、GitHub Pages + サーバーレス API でも同じ画面が動きます。

## 使い方(ローカル)

1. `start.bat` をダブルクリック
2. ブラウザで http://localhost:3690/ が開きます
3. 検索欄に銘柄コード(例: `7203`)か銘柄名(例: `トヨタ`)を入力して検索

終了するには、サーバーの黒いウィンドウを閉じてください。手動起動する場合は `node server.js`。

必要なもの: **Node.js 18 以上**(追加パッケージは不要)

## 公開する(デプロイ)

信用残ページは CORS を返さないため、ブラウザから直接は取得できません。**取得処理を代行する API が必須**です。GitHub Pages は静的配信しかできないので、次の 2 段構えになっています。

| モード | 条件 | できること |
|---|---|---|
| **API モード** | localhost で `server.js` 起動中、または `config.js` に API の URL を設定済み | **任意の銘柄をその場で検索・取得**(ローカルと同じ) |
| **保存済みデータモード** | 上記以外(GitHub Pages に置いただけの状態) | `data/` に保存済みの銘柄のみ表示。GitHub Actions が週次で自動更新 |

### 1. GitHub Pages(画面の配信)

`main` に push すると `.github/workflows/pages.yml` が自動でデプロイします。初回のみリポジトリ側で有効化が必要です。

> Settings → Pages → **Build and deployment / Source** を **GitHub Actions** に設定

この時点では「保存済みデータモード」で動きます(登録済み銘柄の閲覧はできます)。

### 2. API のデプロイ(任意の銘柄を取得できるようにする)

`api/` 以下は Vercel の Node.js サーバーレス関数としてそのまま動きます。

1. [vercel.com](https://vercel.com/new) に GitHub アカウントでログイン
2. このリポジトリを **Import** → 設定は変更せず **Deploy**
   (フレームワークは "Other"、ビルドコマンドなしでOK)
3. 発行された URL(例 `https://kabu-shinyo-checker.vercel.app`)を `config.js` に設定して push

```js
// config.js
window.KABU_API_BASE = "https://kabu-shinyo-checker.vercel.app";
```

以降、GitHub Pages の画面からも任意の銘柄をその場で取得できます。API は CORS を許可しているので別オリジンから呼べます。
なお Vercel の URL 自体を直接開いても、画面 + API が揃った同じサイトとして使えます。

## 週次のデータ自動更新

`.github/workflows/update-data.yml` が **毎週水曜 10:00 (JST)** に `data/` の全銘柄を再取得してコミットします。信用残は東証発表にもとづき週1回(金曜申込ぶんが翌週第2営業日ごろ)更新されるためです。

- 手動実行・銘柄の追加: Actions → **Update margin data** → *Run workflow* → 「追加/更新する銘柄コード」にスペース区切りで入力(例: `7203 6758 9984`)
- ローカルから: `npm run update-data -- 7203 6758`

一度取得した週次データは `data/<銘柄コード>.json` に保存され、次回以降は取得分とマージされます。使い続けると Yahoo!ファイナンスの掲載期間より古い履歴も蓄積されていきます。

## 表示している内容

| 項目 | 説明 |
|---|---|
| 信用買い残 | 信用取引で買われて未決済の株数 |
| 信用売り残 | 信用取引で売られて未決済の株数 |
| 前週比 | 先週からの増減株数と増減率(%) ※増減率は当サイト側で計算 |
| 信用倍率 | 買い残 ÷ 売り残 (倍) |
| 上場来高値・安値 | SBI証券の個別銘柄ページ(ログイン不要)より。上場時まで遡った額面ベースの値 |
| 年初来高値・安値 | SBI証券の個別銘柄ページより。現在値のレンジ内位置も表示 |
| 決算発表予定日 | SBI証券の個別銘柄ページより。残り日数つき |
| 週次の株価(終値) | 信用残の各週(申込日)に対応する終値。テーブルの列とグラフの株価パネルで表示 |

週次の株価は Yahoo(米国)chart API の日足(直近2年)から、各週の申込日にちょうど一致する終値を引いています(休場日は直前の営業日)。直近データなので株式分割の影響はなく正確です。

### 高値・安値について

- **上場来高値/安値**: 上場時まで遡った実際の高値・安値(額面ベース)で、例: トヨタ(7203)は上場来高値 10,460円(2021/9/28)・上場来安値 21円(1950/6/1)。株式分割前の額面価格なので現在値とは基準が異なり、レンジバーは表示していません。
- **年初来高値/安値**: 現在値がレンジ内の下から何%かも表示します。

- データ出典: Yahoo!ファイナンス(信用残時系列・銘柄検索)、SBI証券(株価レンジ・決算日)
- 個人利用を想定しています。取得結果は10分間キャッシュされます
- 表示は取得時点の情報です。投資判断は自己責任でお願いします

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面(検索欄・カード表示・グラフ・履歴テーブル) |
| `config.js` | API の URL 設定(空なら保存済みデータモード) |
| `lib/kabu.js` | データ取得ロジック(ローカル / サーバーレス共通) |
| `lib/cors.js` | API 共通のヘッダー処理 |
| `api/margin.js` `api/search.js` | サーバーレス API(Vercel 用) |
| `server.js` | ローカルサーバー(`api/` を呼び出し + 静的配信) |
| `scripts/update-data.js` | `data/` の一括更新と `data/index.json` の生成 |
| `data/` | 銘柄ごとの週次データ蓄積先 + 一覧 `index.json` |
| `start.bat` | ローカル起動用ショートカット |
| `.github/workflows/` | Pages デプロイ / 週次データ更新 |
